# N.E.X.U.S.

N.E.X.U.S. is an AI interaction and execution system that learns how people work, discovers repetitive workflows, and turns approved intent into verified digital action.

## Features

- Responsive N.E.X.U.S. landing page
- Interactive fixed-position execution sphere
- Free and paid pricing paths
- Cross-platform desktop download page for Windows, macOS, and Linux
- Human approval and adaptive execution messaging

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Routes

- `/` — N.E.X.U.S. landing page
- `/download` — desktop download options
- `/privacy` — privacy policy
- `/terms` — terms of service

## Build

```bash
pnpm build
```
